1. Executive Summary

비전

seoul.is는 글로벌 외국인을 위한 서울/한국 트렌드 자동 큐레이션 플랫폼이다. K-POP, K-DRAMA, 맛집, 핫플레이스, 라이프스타일, 부동산 등 한국 관련 콘텐츠를 50개 이상의 프리미엄 소스에서 자동 수집하여 매일 업데이트한다.

핵심 가치

  • 자동화: 크론 기반 데이터 파이프라인으로 매일 콘텐츠 자동 수집·큐레이션
  • 다국어: IP 기반 자동 언어 감지 (영어 기본, 8개 언어 지원)
  • 모바일 퍼스트: K-POP 관심 글로벌 유저 (동남아, 일본, 중화권) 타겟
  • 수익 다각화: AdSense + 직접 광고 + 여행 제휴 + 쿠폰 플랫폼

    • 타겟 유저

    세그먼트설명비중

    K-Culture 팬K-POP, K-DRAMA 팔로워 (동남아, 일본, 중화권)50% 여행자서울 방문 계획/진행 중인 외국인25% 거주 외국인한국 거주 외국인 (맛집, 라이프스타일, 부동산)15% 비즈니스한국 시장 리서치 목적10%

    2.2 가맹점 (쿠폰 시스템)

    가맹점 등록 신청
  → 관리자 승인
    → 가맹점 대시보드 접근
      → 쿠폰 생성 (할인율, 유효기간, 수량)
        → seoul.is에 쿠폰 노출
          → 유저 다운로드 (QR 생성)
            → 현장 방문 → QR 스캔 사용
              → 가맹점 대시보드에서 사용 현황/유입 트래픽 확인
                → (트래픽 확보 후) 유료 전환

    2.3 광고주 (협찬 콘텐츠)

    광고주 문의 (/advertise 페이지)
  → 견적/계약
    → 관리자 패널에서 협찬 게시물 작성
      → 카테고리 상단 우선 노출 + "Sponsored" 태그
        → 노출 기간 스케줄링 (시작일~종료일)
          → 성과 리포트 자동 생성 (조회수/클릭수)
            → 광고주에게 리포트 전달

  • 기능: 관리자 패널에서 CRUD, 스케줄링, 성과 리포트
